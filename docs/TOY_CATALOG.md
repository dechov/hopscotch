## Toys that are specced but NOT built

The original planning doc `docs/early-planning/hopscotch-widgets-spec.md` catalogs 24 toys (W1–W24)
from early planning, before several were redesigned or replaced during later conversation
(e.g. the physics/ratio trio — Speed Trick, Slow Ratios, Pluck the String — were invented later
and cover related ground differently than however they were originally specced). **This table
of 23 is the accurate, current, built set** — if `docs/early-planning/hopscotch-widgets-spec.md` and this file
disagree, this file wins; the spec doc is historical record, not a live target. If you want to
know exactly which originally-specced toys have no built equivalent, diff W1–W24's concepts in
that doc against the "teaches" column above — that hasn't been done precisely, so treat it as
an open task rather than a known gap list.

## Conventions for adding a new toy

See `CLAUDE.md` "New toy checklist" and `docs/DECISIONS.md` §3 (the embed contract) and §10
(threads). Pick a `thread` from the fixed set (`sound, home, moves, time, timbre, together,
color, ear`) — check `docs/PEDAGOGY.md` if it's not obvious which one fits; thread assignment
is pedagogically meaningful, not decorative.
